# 사이트 설계도(PRD) — COZYADD 코지애드

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
직접 디자인하고 제작하는 소파 브랜드 COZYADD의 브랜드 이야기와 전 제품을 룩북 형태로 보여 주는 사이트.

## 2. 손님
- 누가: 신혼·이사 준비 부부
- 어디서 알고 오나: 인스타그램, 네이버·구글 검색, 쇼룸·매장 방문, 지인 소개·맘카페

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격과 사이즈 (우리 집 거실에 맞는지, 예산 안인지)
2. 원단·색상 고르기 (어떤 천·가죽과 색을 고를 수 있는지)
3. 제작 기간·배송 (입주일에 맞출 수 있는지, 설치까지 해 주는지)
4. 쇼룸에서 앉아보기 (직접 앉아 볼 수 있는 곳과 시간)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 제품·룩북 사진
- 제작 과정 사진·영상 (직접 디자인하고 만드는 모습)
- 보증·소재 정보 (A/S 기간, 내장재·원단 정보 — 실제 내용은 사용자가 준 그대로)
- 후기: 실제 고객 후기가 있음. 사용자가 준 후기만 넣는다(동의 받은 것). 지어내지 않는다

## 5. 누르게 할 버튼 (두 개)
- 버튼 1 이름: 쇼룸 방문 예약 → 누르면: 네이버 예약 페이지로 이동
- 버튼 2 이름: 가격 확인하기(스마트스토어) → 누르면: 네이버 스마트스토어로 이동
- 쇼룸 예약을 더 눈에 띄게 둘지, 두 버튼을 같은 크기로 둘지는 (미정)
- 그 밖의 문의: 페이지 아래 문의 폼(저장 → /admin) + "카카오톡으로 문의" 버튼

## 6. 페이지 구성 (위에서 아래로)
**메인 페이지**
1. 첫 화면 — 한 문장 + 버튼 두 개(쇼룸 방문 예약 · 가격 확인하기)
2. 브랜드 이야기 — 직접 디자인하고 만드는 이유, 제작 과정 사진·영상
3. 룩북 미리보기 — 대표 제품 몇 개 + "전체 룩북 보기"
4. 원단·색상 · 제작 기간·배송 · 보증·소재 안내 (궁금한 것 3번 답)
5. 고객 후기 (사용자가 준 실제 후기만)
6. 쇼룸 안내 — 위치·운영 시간·휴무·전화 + 쇼룸 방문 예약 버튼
7. 문의 폼 + 카카오톡으로 문의 버튼

**룩북 페이지**
- 전 제품을 큰 사진으로. 제품마다 이름 · 사이즈 · 원단/색상 · "스마트스토어에서 가격 보기" 링크

**회원 페이지**
- 회원가입 · 로그인 · 회원 전용 혜택 안내(혜택 내용은 사용자가 줄 때까지 "준비 중") · 개인정보 처리방침 자리

**관리자 페이지 (/admin)**
- 비밀번호로 잠금. 문의함(새 문의 → 연락함 → 완료) + 회원 목록

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 문의 내용 (관심 있는 제품·사이즈 등을 자유롭게)
- 개인정보 수집·이용 동의 (필수)
- 폼 옆에 "카카오톡으로 바로 문의" 버튼 → http://pf.kakao.com/_NpxaiT/chat

- 브랜드 이야기 글, 제작 과정 사진·영상, 후기, 보증·소재 정보 받기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: (미정 — 참고 사이트를 보고 클로드가 정함) · 참고 디자인: https://jacksonchameleon.co.kr/ , https://div-liv.com/ — 그대로 베끼지 않고 분위기만
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin. 카카오톡 채널 버튼도 함께
- 회원가입: 필요 → Supabase Auth(이메일+비밀번호). 개인정보 처리방침 필요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지 → 회원가입·로그인·회원 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
